## Анализ и рекомендации
В ходе тестирования использовались методы [функционального](feature_testing.xlsx) и [регрессионного](regression_testing.xlsx) тестирования.

Пользователю мешают взаимодействовать с приложением баги с **критическим приоритетом**.

### Рекомендации после исправления багов
Обратить внимание на следующие аспекты:
- Сохранение данных пользователя при обновлении приложения
- Реакцию приложения на отсутствие связи
- Отображение деталей маршрута при смене ориентации экрана
- Реакцию карты на жесты "пинч" и "спред"
- Сохранение данных при повторном запуске приложения после полного закрытия
- Функциональность обратной связи
- Функциональность режимов смены темы приложения
